#单词词性释义音标例句操作

💾 玩家存档编辑 先从手机设置里「导出存档」，把文本粘贴到这里

存档保存在玩家自己的手机上（localStorage）。流程：App 内「⚙️设置 → 📤导出存档」→ 复制文本 → 粘贴到下方 → 修改 → 导出 → 手机上「📥导入存档」。
提示：「全部单词标记已掌握」会给词库里每个词写入熟练度 5，重新计算已学数；导入手机后怪物关卡会全部解锁。

🖼️ 装扮 / 开场素材替换 替换后在「发布出包」里一起打包，文件名必须保持不变

装扮图要求：透明背景 PNG（holy 支持 GIF 动图），正面站姿。开场视频 H.264 + AAC 的 mp4。替换文件仅在本次发布包里生效，随时可以移除恢复为包内原图。
